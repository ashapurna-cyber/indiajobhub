# IndiaJobHub

A responsive All India Government + Private Jobs portal template.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Upload the three files (`index.html`, `style.css`, `script.js`) to a GitHub repository.
2. Import the repository into Vercel.
3. Keep the default settings and deploy.

## Add/edit jobs
Open `script.js` and edit the `jobs` array. Each job has:
- title
- organization
- type
- qualification
- state
- category
- deadline
- vacancies
- salary
- apply URL

## Important
The sample jobs are demo data. Replace them with verified current recruitment information and official application links before publishing.
